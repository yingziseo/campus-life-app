# 06 · 开发规划

> 状态：✅ 完成 · 🚧 进行中 · ⏳ 待开始

## 里程碑

### M0 · 原型（v0.1）— 验证业务闭环 🚧

目标：在 Web 端用 9:16 手机框完整演示三端核心流程，用于给商家、学校、合作方展示。

- ✅ 项目初始化：仓库、文档体系、开发日志
- ✅ 后端框架：路由、鉴权、SQLite、统一响应、测试
- ✅ 定价引擎：代金券模式 / 平台定价模式、比价校验、分成计算
- ✅ 订单与分账：快照、券码核销、外卖时间点、流水
- ✅ 校园基础业务接口：跑腿 / 代取快递 / 二手 / 树洞
- ✅ 商家端、客户经理端接口
- ✅ AI 问答预留（FAQ 兜底 + OpenAI 兼容接口）
- ✅ 演示数据 + 56 项自动化测试
- 🚧 H5 原型：学生端 / 商家端 / 客户经理端页面
- 🚧 手机框预览页（身份切换、重置数据）
- 🚧 预览服务部署（8100 端口）

### M1 · 运营后台（v0.2）⏳

- 平台管理后台（PC Web）：学校开通、商家终审、商品抽查（比价截图）、定价参数、FAQ 维护、树洞内容审核
- 图片上传（商品图、二手图、营业执照/食品经营许可证）
- 微信登录 + 手机号快速验证（替换演示验证码）
- 跑腿赏金预付托管、二手站内私信
- 团购按张部分退款
- 数据看板：日活、订单、GMV、各学校对比

### M2 · 配送与结算（v0.3）⏳

- 骑手端：报名、接配送批次、取餐/送达打卡、提成明细
- 配送批次调度：按"学校 + 日期 + 时间点 + 取餐点"自动生成批次与取餐单
- 商家结算：T+1 / 周结报表、提现
- 客户经理佣金提现、经理等级与分成比例
- 用户优惠券、新人立减、拉新奖励

### M3 · 小程序正式版（v1.0）⏳

- 微信小程序前端（原生或 uni-app，复用全部 API）
- 微信支付服务商 + 分账（替换模拟支付，解决二清合规）
- 内容安全：msgSecCheck、举报、黑名单
- MySQL 迁移、Nginx + PHP-FPM 部署、HTTPS、备份
- 试点学校（青岛理工职业学院）上线

### M4 · 扩张（v1.x）⏳

- 多校复制：学校合伙人 / 校园代理模式
- AI 问答接入（盈利后）：知识库 RAG + 问答日志反哺
- 更多品类：驾校、考证培训、打印、理发、二手教材回收
