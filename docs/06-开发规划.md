# 06 · 开发规划

> 状态：✅ 完成 · 🚧 进行中 · ⏳ 待开始

## 里程碑

### M0 · 原型（v0.1）— 验证业务闭环 ✅

- ✅ 项目初始化、文档体系、开发日志
- ✅ 后端框架、定价引擎（代金券 / 平台定价）、订单分账
- ✅ 校园基础业务：跑腿 / 代取快递 / 二手 / 树洞；本地生活：团购 / 校园外卖
- ✅ 商家端、客户经理端；AI 问答预留（FAQ 兜底）
- ✅ H5 原型三端 + 9:16 手机框预览；预览服务部署（8100 端口）

### M1 · 原型完善（v0.2）✅

- ✅ 骑手端：申请加入外卖团队、配送批次、按商家批量取餐、按取餐点批量送达、收入流水
- ✅ 外卖流程：商家出餐 → 骑手取餐 → 送达结算（含骑手提成）
- ✅ 平台管理后台（PC）：数据看板（KPI、7 天趋势、各校经营、待办）、学校开通与送餐配置、商家终审与推广归属、商品比价抽查、订单、资金流水、用户与团队（骑手审核、设客户经理、封禁）、问答知识库与未答问题、树洞审核、平台参数
- ✅ 图片上传：二手多图、店铺封面、商品图、证照（仅后台可见）
- ✅ 树洞举报与自动隐藏
- ✅ 演示数据：近 7 天历史成交、外卖批次、待审核/举报/申请样例
- ✅ 测试：后端 88 项 + 浏览器端到端（四端页面 + 后台 10 页 + 完整外卖链路）

### M2 · 客户反馈优化 + 视觉升级（v0.3）✅

- ✅ 首页推荐：分行业 tab，行业前三为推荐位（商家买广告），其余按销量；周边列表同规则；前台标"广告"
- ✅ 商家购买推荐位（按天计费、占用看板、平台审核）；后台推荐位排期看板 / 审核 / 直接排期
- ✅ 福利群 + 领券中心：首页进群 banner、今日福利、每日定时限量抢券、下单自动用券、取消退回；后台优惠券管理
- ✅ 跑腿 / 代取快递：赏金托管 + 5% 服务费；送达必须拍照留证
- ✅ 校园外卖：骑手在取餐点拍照送达，学生订单可见送达照片
- ✅ 二手担保交易 + 2% 服务费；我买到的 / 我卖出的；学生钱包
- ✅ 收益分配：后台新增「收益分配」页（6 项收入来源、各方分配、示例订单拆分、规则说明），看板增加收入构成
- ✅ 学生端不点名竞品：「全平台低价」「比其他平台省 X 元」，文案后台可改（附《广告法》提示）
- ✅ 订单详情参考美团：小号描边操作按钮（申请退款 / 联系商家 / 再来一单）
- ✅ AI 问答更名「学校百事通」
- ✅ 视觉全面升级：设计令牌、Lucide 线性图标替换全部 emoji、类目渐变封面、四端统一组件
- ✅ 测试：后端 128 项；浏览器端到端覆盖新流程（拍照送达、抢券、确认收货、购买推荐位）

### M3 · 上线准备（v0.4）⏳

- 微信登录 + 手机号快速验证（替换演示验证码）
- 二手站内私信
- 商家结算单（T+1 / 周结）、客户经理 / 骑手 / 学生提现
- 团购按张部分退款；新人立减、拉新奖励
- 消息通知（订单状态、送达提醒、开抢提醒）

### M4 · 小程序正式版（v1.0）⏳

- 微信小程序前端（原生或 uni-app，复用全部 API）
- 微信支付服务商 + 分账（替换模拟支付，解决二清合规）
- 内容安全：msgSecCheck、举报、黑名单
- MySQL 迁移、Nginx + PHP-FPM 部署、HTTPS、备份
- 试点学校（青岛理工职业学院）上线

### M5 · 扩张（v1.x）⏳

- 多校复制：学校合伙人 / 校园代理模式
- AI 问答接入（盈利后）：知识库 RAG + 问答日志反哺
- 更多品类：驾校、考证培训、打印、理发、二手教材回收
