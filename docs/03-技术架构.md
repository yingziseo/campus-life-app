# 03 · 技术架构

## 1. 技术选型

| 层 | 原型（v0.1） | 正式版（v1.0） | 理由 |
|---|---|---|---|
| 后端语言 | **PHP 8.0**（无框架、无 Composer 依赖） | PHP 8.x + 同一套代码分层 | 服务器现成可用，部署零成本；分层清晰，后期可平滑迁移到 Laravel/ThinkPHP |
| 数据库 | **SQLite 3**（单文件 `server/storage/campus.db`，WAL 模式） | MySQL 8 | 原型免运维；SQL 基本通用，迁移只需改 DSN 和少量方言 |
| 前端原型 | **H5 单页（Vue 3 本地引入，无构建）** + 9:16 手机框预览页 | 微信小程序（原生或 uni-app） | 浏览器即可预览，页面结构与小程序一一对应，后端 API 直接复用 |
| 预览服务 | PHP 内置服务器（systemd 托管，端口 8100） | Nginx + PHP-FPM | 原型不改动服务器现有 Nginx 站点 |
| 支付 | 模拟支付 | 微信支付服务商 + 分账 | 见 02 文档合规部分 |
| AI 问答 | 本地 FAQ 匹配 | OpenAI 兼容接口（已预留） | 见 01 文档第 6 节 |

## 3. 后端分层

```
请求 → public/index.php → Router（匹配路由 + Auth 鉴权）→ Controller（参数校验、组装输出）
                                                     ↘ Service（业务规则：定价、订单、分账）→ Db（SQLite）
```

- **Controller** 只做参数读取校验、权限判断、字段裁剪（例如对学生隐藏商家结算价）。
- **Service** 承载核心业务规则，可被 Controller、Seeder、测试复用。
- **Db** 提供 `all/one/value/insert/update/transaction`；事务可嵌套（并入外层）；读出时按 SQLite 存储类型还原 int/float（PHP 8.0 pdo_sqlite 默认全返回字符串）。

## 4. 接口约定

- 前缀 `/api`，JSON 请求与响应。
- 成功：`{"code": 0, "data": ...}`；失败：`{"code": <HTTP状态码>, "msg": "给用户看的提示"}`，同时设置对应 HTTP 状态码。
- 鉴权：`Authorization: Bearer <token>`，token 存 `sessions` 表，有效期 30 天。
- 状态码：401 未登录、403 无权限、404 不存在、412 前置条件（未选学校/未入驻）、422 参数或业务校验失败。
- **金额**：请求参数以「元」传入（如 `"price": "25.5"`），响应一律以「分」返回（整数），前端负责格式化。
- 角色权限在 `routes.php` 第三个参数声明：`''` 公开、`'login'` 任意登录用户、`'merchant'` / `'manager'` 指定角色（admin 可访问全部）。

## 5. 前端原型与小程序的对应

| H5 原型 | 微信小程序 |
|---|---|
| 顶部导航栏 + 右上角胶囊 | 小程序自定义导航 / 系统胶囊 |
| 底部 TabBar（按身份切换） | `app.json` tabBar（不同身份可用不同分包入口） |
| `#/xxx` hash 路由 | `pages/xxx/xxx` 页面 |
| `api()` 封装 fetch + token | `wx.request` 封装 |
| localStorage 存 token | `wx.setStorageSync` |
| 手机号 + 验证码 1234 | `wx.login` + 手机号快速验证 |
| 模拟支付按钮 | `wx.requestPayment` |

转写小程序时：页面结构与样式类名基本可复用，后端无需改动。

## 6. 本地运行

```bash
cd server
php bin/init-db.php --fresh     # 建表 + 演示数据
bin/serve.sh 8100               # 启动，浏览器打开 http://<服务器IP>:8100/
php tests/run.php               # 后端测试（单元 + 接口集成）
cd ../tests/e2e && npm i && npm test   # 浏览器端到端测试（需先启动预览服务）
```

依赖：PHP ≥ 8.0，扩展 `pdo_sqlite`、`mbstring`、`curl`。

## 8. 部署（原型预览）

服务器已有多个 Nginx 站点，原型 **不修改现有 Nginx 配置**，以独立 systemd 服务运行：

```ini
# /etc/systemd/system/campus-life-preview.service
[Service]
WorkingDirectory=/root/小程序/server
ExecStart=/usr/bin/php -S 0.0.0.0:8100 -t /root/小程序/web /root/小程序/server/router.php
Environment=APP_ENV=dev
Restart=always
```

外网访问需在云服务器安全组放行 TCP 8100。正式环境改用 Nginx + PHP-FPM，`root` 指向 `web/`，`/api` 交给 `server/public/index.php`。
