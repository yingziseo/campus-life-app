# 04 · 数据库设计

> 完整 DDL：[`server/database/schema.sql`](../server/database/schema.sql)
> 约定：金额 INTEGER 单位分；时间 TEXT `YYYY-MM-DD HH:MM:SS`（本地时间）；JSON 配置存 TEXT。

## ER 概览

```
schools 1─┬─n users ──1 merchants(owner) ──n deals
          │     │ (manager) 1──n merchants.manager_id
          ├─n errands / market_items / treehole_posts ─n treehole_comments / treehole_likes
          └─n orders ──n coupons
                  └──n ledger（分账流水）
market_items ──n market_orders（二手担保交易）
merchants / deals ──n promotions（首页推荐位）
coupon_templates ──n user_coupons ──1 orders（平台优惠券）
faqs / ai_logs（学校百事通）   settings（平台参数）   sessions（登录态）
```

## 表清单

| 表 | 说明 | 关键字段 |
|---|---|---|
| `settings` | 平台可调参数 | key, value(JSON) |
| `schools` | 学校 | status(active/preparing/applying), is_pilot, delivery_slots, delivery_points |
| `users` | 统一账号 | phone, role(student/merchant/manager/admin), school_id, invite_code(经理), rider_status(none/pending/approved 骑手兼职), status(active/banned) |
| `sessions` | 登录 token | token, user_id, expires_at |
| `errands` | 跑腿 / 代取快递 | type, reward（托管）, fee（服务费）, proof_image（送达照片）, status, runner_id, express_code |
| `market_items` | 二手 | category, price, original_price, images(JSON), status（reserved = 交易中） |
| `market_orders` | 二手担保交易 | item_id, buyer_id, seller_id, price, fee, status(paid/completed/cancelled) |
| `treehole_posts` | 树洞帖 | anon_name, tag, like_count, comment_count, report_count, status, user_id(仅后台) |
| `treehole_reports` | 举报 | (post_id, user_id) 唯一, reason |
| `treehole_comments` | 树洞评论 | post_id, anon_name |
| `treehole_likes` | 点赞 | (post_id, user_id) 主键 |
| `merchants` | 商家 | owner_user_id, **manager_id(推广绑定)**, category, takeout_enabled, cover, license_image, status |
| `deals` | 商品/套餐 | type(groupbuy/takeout), image, pricing_mode, competitor_price, merchant_settle, voucher_face/cost, list_price, sale_price |
| `orders` | 订单 | 金额快照：goods/total/competitor/merchant_amount, platform_gross, manager_commission, rider_commission, coupon_discount, platform_net；外卖：delivery_date/slot/point, rider_id, ready_at, picked_at, proof_image |
| `coupons` | 团购券码 | code(12位), status(unused/used/refunded) |
| `ledger` | 分账流水 | school_id, source(order/errand/market/promotion), order_id, ref_id, party_type(merchant/manager/platform/rider/student), party_id, amount（可为负）, kind |
| `promotions` | 首页推荐位 | school_id, category, position(1~3), deal_id, start/end_date, days, fee, status(pending/active/rejected/ended), source |
| `coupon_templates` | 平台优惠券模板 | amount, threshold, scope(all/takeout/groupbuy), daily_quota, start_time, valid_days, status |
| `user_coupons` | 用户领到的券 | (template_id, user_id, claim_date) 唯一, expires_at, status, order_id |
| `faqs` | 问答知识库 | school_id(NULL=通用), keywords, hits |
| `ai_logs` | 问答记录 | question, answer, source(faq/ai/none) |

## 状态机

- **errands**：`open → accepted → delivered → completed`，`open → cancelled`
- **orders（团购）**：`pending_pay → paid → completed`（券全部核销），`pending_pay → cancelled`，`paid → refunded`
- **orders（外卖）**：`pending_pay → paid →（商家出餐）ready →（骑手取餐）delivering →（骑手送达）completed`；仅 `paid` 可退款
- **merchants**：`pending → approved / rejected`
- **market_orders**：`paid →（买家确认收货）completed`，`paid →（任一方取消）cancelled`
- **promotions**：`pending → active / rejected`，`active → ended`（提前下线）
- **user_coupons**：`unused → used`（下单占用），订单取消 / 退款时退回 `unused`

## 迁移到 MySQL 的注意点

- `INTEGER PRIMARY KEY AUTOINCREMENT` → `BIGINT UNSIGNED AUTO_INCREMENT`
- `datetime('now','localtime')` 默认值 → `CURRENT_TIMESTAMP`
- `INSERT ... ON CONFLICT DO UPDATE` → `INSERT ... ON DUPLICATE KEY UPDATE`（仅 `Settings::set`）
- `strftime('%Y-%m', ...)` → `DATE_FORMAT(..., '%Y-%m')`（仅客户经理月佣金统计）
