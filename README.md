# 校园生活 · Campus Life

面向大学生的校园综合服务平台（微信小程序方向）。试点学校：**青岛理工职业学院**。

- **板块一 · 校园基础业务**：跑腿、代取快递、二手交易、树洞
- **板块二 · 周边本地生活**：餐饮团购、校园外卖（固定时间点集中配送）、网吧、台球、民宿……每个商品标注"比其他平台省 X 元"（学生端不点名竞品）
- **客户经理推广体系**：邀请码绑定商家，按订单差价分成
- **校园外卖团队**：学生兼职骑手，固定时间点批次取餐、集中送达
- **平台管理后台**：看板、学校/商家/商品/订单/流水/用户/树洞/知识库/参数
- **平台收入**：商品差价、配送费结余、跑腿 / 二手服务费（5% / 2%）、首页推荐位广告；福利群优惠券由平台补贴
- **学校百事通**：AI 问答接口已预留，当前由本地知识库兜底

当前阶段：**v0.3 原型**（PHP 8 + SQLite，Web 端 9:16 手机框预览；图标为 Lucide 线性图标，见 `web/shared/`）

- 预览：http://43.159.38.19:8100/ （学生 / 商家 / 客户经理 / 骑手四端一键切换）
- 管理后台：http://43.159.38.19:8100/admin/

## 快速开始

```bash
cd server
php bin/init-db.php --fresh   # 建表 + 演示数据
bin/serve.sh 8100             # 打开 http://localhost:8100/ 进入手机框预览
php tests/run.php             # 运行测试
```

依赖：PHP ≥ 8.0（扩展 pdo_sqlite、mbstring、curl），无需 Composer / Node。
