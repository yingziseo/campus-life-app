# 校园生活 · Campus Life

面向大学生的校园综合服务平台（微信小程序方向）。试点学校：**青岛理工职业学院**。

- **板块一 · 校园基础业务**：跑腿、代取快递、二手交易、树洞
- **板块二 · 周边本地生活**：餐饮团购、校园外卖（固定时间点集中配送）、网吧、台球、民宿……每个商品"比美团省 X 元"
- **客户经理推广体系**：邀请码绑定商家，按订单差价分成
- **AI 自助问答**：接口已预留，当前由本地 FAQ 兜底

当前阶段：**v0.1 原型**（PHP 8 + SQLite，Web 端 9:16 手机框预览）

## 快速开始

```bash
cd server
php bin/init-db.php --fresh   # 建表 + 演示数据
bin/serve.sh 8100             # 打开 http://localhost:8100/ 进入手机框预览
php tests/run.php             # 运行测试
```

依赖：PHP ≥ 8.0（扩展 pdo_sqlite、mbstring、curl），无需 Composer / Node。
